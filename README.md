 Amazon Sales Analysis – Power BI Data Analytics Project

##  Overview

This project uses Power BI to analyze Amazon sales data and extract actionable insights through a fully interactive dashboard. The aim was to visualize and monitor sales performance, identify trends, and support data-driven business decisions.

---

##  Problem Statement

> How can Amazon's sales data be used to uncover key trends, best-performing categories, and customer behavior across time and location?

### Goals:

* Track sales performance across regions and categories
* Identify revenue trends and seasonal peaks
* Analyze top-selling products and customer order patterns
* Present findings in an interactive and visually appealing dashboard

---

##  Tools & Technologies Used

* **Power BI Desktop**

  * Power Query for data transformation
  * DAX (Data Analysis Expressions) for calculated columns and KPIs
  * Slicers, Filters, Drill-Downs for interactivity
  * Multiple visual types: Bar, Line, Map, Pie, Cards

* **Excel (Initial Cleanup)** – Optional for quick data structuring

---

##  Process

### 1. Data Preparation

* Cleaned and transformed raw CSV using Power Query
* Created calculated columns: Total Sales, Order Month, Year, and City-State
* Normalized and grouped data for aggregation

### 2. Data Modeling

* Defined relationships between tables (Products, Regions, Orders)
* Used DAX to calculate:

  * Total Revenue
  * Monthly Sales Trend
  * Top 5 Products by Revenue
  * Sales by Region

### 3. Dashboard Design

* **Main Pages:**

  * **Executive Overview** (KPIs, revenue, order volume)
  * **Product Insights** (top items, category-wise performance)
  * **Time Series** (monthly trend line, YoY comparison)
  * **Regional Breakdown** (map view of sales by state/city)
* Fully interactive with slicers for time, product, and region

---

## 🔍 Key Insights

* 🏆 **Top Category:** Electronics led sales with 40% share
* 📈 **Peak Month:** November saw the highest revenue due to festive sales
